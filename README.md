# Choisto DL: Jellyfin plugin repository

This repository only holds the releases of the Choisto DL plugin for Jellyfin 12.1 and later.

To install it, open Dashboard → Plugins → Repositories on your Jellyfin server and add:

```
https://github.com/Choisto/Choisto-DL-Releases/releases/latest/download/manifest.json
```

Choisto DL then shows up in the catalogue. Updates show up there too.
